# 工具执行展示 PRD

> 状态：PRD 已确认
> 模块编号：04

## 1. 场景意图

### 1.1 业务背景与目标

AI 在对话中调用 pi 的工具系统（read / write / edit / bash / grep 等）执行编程操作。forge 以卡片形式展示工具调用的过程、参数与结果，让用户清楚 AI 做了什么；对文件编辑类工具提供 Diff 可视化，直观呈现代码变更。工具卡片在对话流中穿插，与对话上下文紧耦合。

### 1.2 场景清单

| 场景 ID | 场景 | 业务价值 | 必须达成 | 明确不做 |
|---|---|---|---|---|
| TE-S01 | 工具调用卡片 | 展示 AI 调了什么工具 | 工具名 + 参数 + 执行状态卡片 | 不隐藏工具执行过程 |
| TE-S02 | 工具结果展示 | 展示工具执行结果 | 结果内容渲染（文本/代码） | 不截断关键结果；不渲染危险 HTML |
| TE-S03 | 文件 Diff 展示 | 展示文件编辑差异 | edit 工具的变更前后对比可视化 | 不丢失变更上下文 |
| TE-S04 | 工具状态流转 | 实时显示执行状态 | 运行中 -> 完成/出错，实时更新 | 不卡顿 |

### 1.3 边界与权限

- **不可接受方案**：隐藏工具执行过程；Diff 不可读；结果丢失；渲染任意 HTML（XSS）。
- **必须满足条件**：工具卡片在对话流穿插；结果内容安全渲染（复用模块 03 白名单）；Diff 可视化；状态实时。
- **角色与权限边界**：单用户；工具执行由 pi 控制，forge 仅展示；无 per-tool 审批（跟 pi 一致）。

### 1.4 已确认业务决策

- 工具执行展示复用 ai-coding 前端（tool 卡片组件）。
- Diff 可视化（文件编辑前后对比）。
- 工具消息在对话流穿插展示（模块 03 对话区承载）。
- 工具结果内容渲染复用模块 03 的 Markdown 安全渲染（防 XSS）。

## 2. 关键技术决策

| 决策 ID | 影响场景 | 关键理由 | 备选方案 | 推荐方案 | 确认结果 |
|---|---|---|---|---|---|
| TD-TE-01 | TE-S03 | Diff 展示方式影响可读性与前端实现 | A: 并排对比（旧/新两栏）；B: 行内 unified（+/- 标记）；C: 可切换 | A（并排，直观，v1 简单；切换留后续） | 已确认 |
| TD-TE-02 | TE-S02 | 长结果展示策略影响可读性与性能 | A: 长结果折叠（默认折叠，点击展开）；B: 全展开 | A（折叠 + 展开，避免刷屏） | 已确认 |
| TD-TE-03 | TE-S01 | 工具卡片位置影响 UI 架构与上下文关联 | A: 对话流穿插（inline，紧贴触发消息）；B: 独立工具面板 | A（对话流穿插，贴合上下文） | 已确认 |

> **已采用的常规默认项**：工具状态实时流转（运行中/完成/出错），运行中显示 spinner；卡片可折叠（头常驻，内容可收起）；Diff 高亮增删行；出错标红 + 错误信息。

> **开发期风险（已计入 overview）**：pi 工具事件 -> `CanonicalEvent` 工具部分映射完整性（含 edit 的 oldText/newText 用于 Diff）；Diff 超大文件性能。

## 3. 详细设计

### 3.1 模块概述与边界

- **业务目标**：展示 AI 工具调用的过程、参数、结果，文件编辑提供 Diff 可视化。
- **核心职责**：工具卡片渲染、结果展示、Diff 可视化、状态流转。
- **核心业务对象**：工具事件（ToolEvent）= 工具名 + 参数 + 状态 + 结果（edit 类含 oldText/newText）。
- **涉及角色**：单用户。
- **前置条件**：会话运行中，AI 调用了工具。
- **上下游与职责边界**：
  - 上游：模块 03 对话与消息（工具卡片在对话流穿插）；pi（工具事件）。
  - 下游：无。
  - 数据边界：工具事件由 pi 产生，forge 仅渲染展示。

### 3.2 核心流程与状态

```
AI 调工具 -> 工具卡片出现(运行中) -> 执行 -> 结果返回 -> 卡片更新(完成/出错)
   -> 若 edit 类工具 -> 渲染并排 Diff
状态: 运行中 -> 完成 / 出错
```

### 3.3 功能点

#### 功能点：TE-S01 工具调用卡片

- **目标**：展示 AI 调用了什么工具。
- **前置条件**：AI 调用工具。
- **业务规则**：卡片含工具名 + 参数 + 状态；对话流穿插（TD-TE-03 A）；卡片可折叠。
- **业务数据**：工具名、参数、状态。
- **交互与反馈**：卡片在对话流出现，紧贴触发消息；卡片头常驻（工具名 + 状态）；点击展开看参数。
- **权限边界**：无（仅展示）。
- **合法/非法状态流转**：运行中 -> 完成/出错（合法）。
- **异常与边界**：工具执行失败 -> 卡片标红 + 错误信息。
- **数据一致性与幂等**：卡片与触发消息关联；同一工具事件只渲染一张卡片。
- **跨模块影响**：模块 03 对话流承载卡片。

验收标准：

| AC ID | 验收事实 | 验证层级 | 场景 | 风险维度 | 边界条件 |
|---|---|---|---|---|---|

| AC-TE-002 | 工具卡片可折叠/展开（头常驻） | E2E | 正常流程 | 交互 | - |

#### 功能点：TE-S02 工具结果展示

- **目标**：展示工具执行结果。
- **前置条件**：工具执行完成。
- **业务规则**：结果内容渲染（文本/代码高亮）；长结果折叠 + 展开（TD-TE-02 A）；安全渲染（白名单，复用模块 03）。
- **业务数据**：结果内容。
- **交互与反馈**：结果在卡片内显示；长结果默认折叠，点击展开查看全部。
- **权限边界**：白名单安全渲染防 XSS（硬约束）。
- **合法/非法状态流转**：不适用。
- **异常与边界**：结果为空 -> 显示"无输出"；结果超长 -> 折叠 + 提示长度。
- **数据一致性与幂等**：结果与工具对应，不串。
- **跨模块影响**：复用模块 03 渲染能力。

验收标准：

| AC ID | 验收事实 | 验证层级 | 场景 | 风险维度 | 边界条件 |
|---|---|---|---|---|---|

| AC-TE-004 | 长结果默认折叠，可点击展开查看全部 | E2E | 正常流程 | 性能/可读性 | 超长 grep 输出 |
| AC-TE-005 | 结果中危险 HTML 被过滤不执行 | unit | 安全 | 安全/XSS | 结果含恶意 HTML |

#### 功能点：TE-S03 文件 Diff 展示

- **目标**：展示文件编辑差异。
- **前置条件**：edit 类工具执行（含 oldText/newText）。
- **业务规则**：并排对比（TD-TE-01 A，旧/新两栏）；高亮增删行；显示文件路径。
- **业务数据**：文件路径、oldText、newText。
- **交互与反馈**：edit 工具卡片内显示并排 Diff，左旧右新，增删行高亮。
- **权限边界**：无。
- **合法/非法状态流转**：不适用。
- **异常与边界**：大文件 Diff -> 虚拟滚动或限制行数保证性能；Diff 数据缺失（无 oldText）-> 降级显示 newText。
- **数据一致性与幂等**：Diff 与实际文件变更一致。
- **跨模块影响**：依赖 edit 工具事件含 oldText/newText（pi 事件映射）。

验收标准：

|---|---|---|---|---|---|

#### 功能点：TE-S04 工具状态流转

- **目标**：实时显示工具执行状态。
- **前置条件**：工具执行中。
- **业务规则**：运行中（spinner）-> 完成（绿勾）/ 出错（红标）；实时更新。
- **业务数据**：状态。
- **交互与反馈**：卡片状态实时变化，运行中显示 spinner，完成显示绿勾，出错标红。
- **权限边界**：无。
- **合法/非法状态流转**：运行中 -> 完成/出错（合法）；完成 -> 运行中（非法）。
- **异常与边界**：状态更新延迟 -> 最终一致（以 pi 最终状态为准）。
- **数据一致性与幂等**：状态与 pi 工具执行一致。
- **跨模块影响**：pi 工具事件 -> CanonicalEvent 映射。

验收标准：

### 3.4 页面承载

- **页面路径与访问权限**：对话区内（工具卡片穿插，会话打开后可见）。
- **页面结构**：
```
对话区
┌──────────────────────────┐
│ [user 消息]               │
│ ┌ tool: edit src/a.ts ──┐ │
│ │ 状态: 完成 ✓           │ │
│ │ ┌旧──────┬新──────┐    │ │
│ │ │ -old   │ +new   │ Diff│ │
│ │ └────────┴────────┘    │ │
│ └────────────────────────┘ │
│ [assistant 消息]          │
└──────────────────────────┘
```
- **操作入口、按钮和链接**：卡片头点击（折叠/展开）；结果区点击（展开长结果）；Diff 查看（只读）。
- **弹窗、loading、成功/失败反馈**：运行中 spinner；完成绿勾；出错标红 + 错误信息；空结果显示"无输出"。
- **失败时的上下文和数据保留**：工具出错卡片保留显示错误信息，不影响对话流其他内容。

### 3.5 非功能要求

- **性能与容量**：工具卡片渲染 < 50ms；小变更 Diff 渲染 < 100ms；大文件 Diff 虚拟滚动 60fps。
- **安全与审计**：结果白名单渲染防 XSS；无 per-tool 审批。
- **可用性与降级**：工具出错不崩溃对话；大 Diff 降级（虚拟滚动/限制行数）；Diff 数据缺失降级显示 newText。
- **可观测性**：工具执行事件（工具名、状态、耗时）记日志。
- **兼容性**：复用 ai-coding tool 卡片 + Diff 组件。
