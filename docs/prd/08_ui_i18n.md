# UI 国际化（中/英）PRD

> 状态：PRD 已确认（2026-09-22 用户「开工」批准）

## 1. 场景意图

### 1.1 业务背景与目标

forge-ui 当前无任何 i18n 基础设施：28 个组件与相关 utils（tooltip、slashCommand 展示文案等）全部硬编码中文，`package.json` 无 i18n 依赖。随着英文用户使用场景出现，App 自身界面文字需要支持中英文切换。

本模块目标：**仅针对 App UI 静态文案**提供简体中文 / English 双语能力，设置页一键切换、即时生效、持久记忆。AI 对话内容、模型输出、主进程推送的动态文案不在本期范围。

### 1.2 场景清单

| 场景 ID | 场景 | 业务价值 | 必须达成 | 明确不做 |
|---|---|---|---|---|
| I18N-S01 | 语言切换 | 用户可按偏好阅读界面 | 设置页新增「语言」项：简体中文 / English / 跟随系统；切换后全站界面文案即时刷新，无需重启；多窗口（画布模式）同步生效 | 不做逐窗口独立语言 |
| I18N-S02 | 首启跟随系统 | 零配置即得合理语言 | 无已存偏好时按 `navigator.language` 判定：`zh*` → zh-CN，其余 → en；永不出现"无语言"状态 | 不做更多语种（仅中英） |
| I18N-S03 | 偏好持久化 | 重启记住选择 | 刷新/重启/新开窗口均恢复上次语言；「跟随系统」状态在系统语言变化后下次启动生效 | 不做语言包在线下载/导入导出 |
| I18N-S04 | 存量文案全量迁移 | 切英文后无中文残留 | 全部组件模板与展示层常量改经 `t()` 取键；验收标准：`forge-ui/src` 组件/展示常量层硬编码中文清零（代码注释、AI 消息内容、mock 演示数据除外） | 不改主进程/core/desktop 任何文案 |

### 1.3 边界与权限

- **不可接受方案**：翻译 AI 对话/模型输出内容；为两语种场景引入重型 i18n 框架改造整条构建链。
- **必须满足条件**：纯 UI 层实现，**主进程零改动**（语言只被渲染进程消费，与主题不同——主题需主进程建窗时读取，语言不需要）；字典键类型安全（拼错键编译期报错，不允许 `any`）；缺键回退 zh-CN 并 console.warn，界面不得出现空白文案。
- **角色与权限边界**：单用户本地应用，无角色区分。

### 已采用的常规默认项

- 语言选项文案：「简体中文」「English」「跟随系统 (System)」，且这三项**不随界面语言翻译**（各语言用自身书写，业界惯例）。
- 设置页入口位置：外观/主题设置相邻处新增「语言」单选组。
- 字典文件：`src/i18n/zh-CN.ts`、`src/i18n/en.ts`、`src/i18n/index.ts`（locale 状态 + t 实现），键名按界面区域分组（`common.* / settings.* / titlebar.* / input.* / message.* / tool.* …`）。
- 数字/日期不做 locale 格式化（沿用现有展示）。

## 3. 详细设计

### 3.1 模块概述与边界

- 业务目标：forge-ui 界面文案中英双语，设置页切换即时生效并持久。
- 核心职责：locale 状态管理（检测/切换/持久/多窗口同步）、双字典维护、`t()` 取值与插值、存量文案全量迁移。
- 核心业务对象：`Locale = 'zh-CN' | 'en'`（内部生效值）；`LocalePreference = 'zh-CN' | 'en' | 'system'`（持久化偏好）；字典键（点路径字符串，类型约束）。
- 涉及角色：单用户本地应用，无角色区分。
- 前置条件：无（纯前端，boot 前可读 localStorage）。
- 上下游与职责边界：forge-core / forge-desktop 零改动；主进程推送的动态文案（toast detail、错误消息、AI 内容）原样渲染，不经 `t()`。

### 3.2 核心流程与状态

```
App 启动 → 读 localStorage['forge.locale']（无值→'system'）
  → system：navigator.language.startsWith('zh') ? zh-CN : en
  → 生效 locale 注入模块级 ref → 组件 t() 渲染
用户在设置页切换 → 写 localStorage + 更新 ref（当前窗口即时重渲染）
其余窗口 ← 'storage' 事件 → 更新各自 ref
```

### 3.3 功能点

#### 功能点：I18N-F01 i18n 核心模块

- 目标：提供 locale 状态、`t()`、持久化与回退链。
- 前置条件：无。
- 业务规则：`t(key, params?)` 回退链 当前语言→zh-CN→原样返回 key 并 console.warn；插值语法 `{name}`（仅字符串替换，无 HTML）；`setPreference(p)` 写 localStorage 并更新生效值；`system` 判定只在读取时执行。
- 业务数据：`localStorage['forge.locale']`（值域 `zh-CN|en|system`，缺省 `system`）。
- 交互与反馈：无 UI（由 F02 承载入口）。
- 权限边界：仅渲染进程 localStorage，不触文件系统。
- 合法/非法状态流转：偏好三态 → 生效值恒为二态之一；非法存储值（手改）→ 视同 `system`。
- 异常与边界：localStorage 不可用（隐私模式）→ 内存态生效本次会话，读写静默降级不报错。
- 数据一致性与幂等：重复 set 同值无副作用；storage 事件自窗口回环忽略（值相等不触发重渲染）。
- 跨模块影响：无后端改动。

#### 功能点：I18N-F02 设置页语言切换器

- 目标：提供「语言」单选组：简体中文 / English / 跟随系统。
- 前置条件：设置页可打开。
- 业务规则：选项文案不随界面语言翻译（各语言自身书写）；位置紧邻外观/主题设置；当前值高亮。
- 业务数据：读写走 F01 偏好 API。
- 交互与反馈：点选即生效，无保存按钮、无确认；成功静默（界面本身即反馈）。
- 权限边界：无。
- 合法/非法状态流转：三选一，无中间态。
- 异常与边界：持久化失败仍切换成功（内存态）。
- 数据一致性与幂等：重复点选当前项无变化。
- 跨模块影响：无。

- 交互与反馈：视觉零回归（仅文字来源改变）。

- 跨模块影响：forge-ui 既有单测断言中文文案处需同步改为键值或英文/中文双语兼容断言。

### 3.4 页面承载

- 页面路径与访问权限：设置页（SettingsPanel 既有入口）→「外观」区新增「语言」行。
- 页面结构：三选一单选组，样式复用主题切换既有控件形态。
- 操作入口、按钮和链接：无新增入口，语言行即入口。
- 表单字段与业务校验：`ui.language ∈ {zh-CN, en, system}`，非法值回退 system。
- 弹窗、loading、成功/失败反馈：无（即时生效）。
- 失败时的上下文和数据保留：持久化失败保留内存态并 warn。

### 3.5 非功能要求

- 性能与容量：字典为静态 import，两字典合计 < 30KB 源码；t() 为 O(1) Map/对象取值，渲染开销可忽略。
- 安全与审计：无外部输入执行；localStorage 值白名单校验。
- 可用性与降级：任何异常（缺键/存储不可用/非法值）界面永不空白。
- 可观测性：缺键 console.warn 英文日志（含键名）。
- 兼容性：Electron 内 Chromium 全支持；`storage` 事件行为已验证。
