# 模块三：技能管理

## 模块概述

### 业务目标
管理 AI 助手的技能配置，包括技能定义、附件文件和动态写入，使助手能够调用特定工具或遵循特定工作流程。

### 核心职责
- 技能的完整生命周期管理
- 技能附件文件管理
- 助手-技能关联管理
- 技能动态写入工作目录

### 涉及角色
- 开发者（创建、编辑、删除技能）
- 助手（执行时读取技能）

### 核心业务对象
- **技能（Skill）** - 技能定义，包含名称、描述、内容
- **技能文件（SkillFile）** - 技能的附件文件
- **助手技能关联（AgentSkill）** - 助手与技能的多对多关系

### 前置条件
- 无

---

## 模块边界

### 上游模块
| 模块 | 输入 |
|------|------|
| 助手配置 | 关联技能到助手 |

### 下游模块
| 模块 | 输出 |
|------|------|
| 任务执行 | 执行任务时将技能写入工作目录 |

### 数据边界
- 一个技能可以有零个或多个附件文件
- 一个技能可以关联零个或多个助手
- 技能同时存在于数据库和本地文件系统

### 职责边界
- 本模块不负责 Claude Code CLI 的技能发现机制
- 本模块不负责本地 ~/.claude/skills/ 目录的维护

### 技能执行流程

```
任务开始执行
    │
    ├── 任务执行模块获取助手关联的技能列表
    │
    ├── 遍历技能列表
    │     │

    │     ├── 写入技能文件: SKILL.md (技能内容)
    │     │

    └── Claude Code CLI 启动

              └── 技能可用
```

## 功能点

### 功能 1：创建技能

**功能目标/解决的问题**
用户需要创建新的技能供助手使用。

**前置条件**
- 无

**业务规则**
- 技能名称为必填项，长度 1-200 字符
- 描述为选填，最长 2000 字符
- 内容为必填，最长 500000 字符
- 名称在数据库技能中唯一（不与本地技能冲突校验）

**业务数据**
- 技能名称：用于创建目录和标识
- 描述：技能的用途说明
- 内容：技能的具体指令（写入 SKILL.md）

**交互流程**
1. 用户点击「新建技能」按钮
2. 系统弹出技能创建弹窗
3. 用户填写表单
4. 用户点击「保存」按钮
5. 系统验证必填字段
6. 保存成功后关闭弹窗，刷新列表显示新技能

**异常与边界**
- 名称为空：提示「名称不能为空」
- 名称超长：提示「名称不能超过 200 字符」
- 内容为空：提示「内容不能为空」

**验收标准**

| 验收项 | 验证方式 | 测试场景 | 边界条件 |
|-------|---------|---------|---------|
| 创建成功 | E2E | 填写所有必填字段，点击保存 | - |
| 名称必填 | E2E | 名称为空时保存 | 空白字符串 |
| 内容必填 | E2E | 内容为空时保存 | 空白字符串 |
| 默认值正确 | 单元测试 | 不填写描述，查看默认值 | - |

### 功能 2：编辑技能

**功能目标/解决的问题**
用户需要修改已存在技能的内容。

**前置条件**
- 技能存在

**业务规则**
- 名称、描述、内容均可修改
- 修改后下次执行任务时会更新写入的文件

**交互流程**
1. 用户点击技能列表中的「编辑」按钮
2. 系统弹出编辑弹窗，预填当前数据
3. 用户修改表单
4. 用户点击「保存」按钮
5. 系统保存修改
6. 关闭弹窗，刷新列表

**异常与边界**
- 名称重复：提示「技能名称已存在」

**验收标准**

| 验收项 | 验证方式 | 测试场景 | 边界条件 |
|-------|---------|---------|---------|
| 编辑成功 | E2E | 修改所有字段并保存 | - |
| 内容更新 | 单元测试 | 编辑后检查数据库内容 | - |

### 功能 3：删除技能

**功能目标/解决的问题**
用户需要删除不需要的技能。

**前置条件**
- 技能存在

**业务规则**
- 删除技能会级联删除相关的 skill_file 记录
- 删除技能不会删除已写入工作目录的文件（由 GC 清理）
- 有关联助手的技能也可删除（取消关联即可）

**交互流程**
1. 用户点击技能列表中的「删除」按钮
2. 系统弹出确认对话框
3. 用户点击「确认删除」
4. 系统执行删除
5. 刷新列表

**异常与边界**
- 有关联助手：提示「该技能已关联到 {n} 个助手，删除后将解除关联」

**验收标准**

| 验收项 | 验证方式 | 测试场景 | 边界条件 |
|-------|---------|---------|---------|
| 删除成功 | E2E | 确认删除 | 无关联助手 |
| 关联提示 | E2E | 删除有关联助手的技能 | 有关联 |
| 级联删除文件 | 单元测试 | 删除技能后检查 skill_file 表 | - |

### 功能 4：技能附件文件管理

**功能目标/解决的问题**
用户需要为技能添加示例文件或参考文档。

**前置条件**
- 技能存在

**业务规则**
- 附件文件路径相对于技能目录
- 附件内容直接存储在数据库
- 附件会在技能写入时被写入对应路径

**业务数据**
- 文件路径：相对于技能目录的路径
- 文件内容：文件的原始内容

**交互流程**
1. 用户在技能详情页点击「添加附件」
2. 系统弹出文件上传弹窗
3. 用户输入文件路径和内容
4. 用户点击「保存」
5. 系统保存附件
6. 刷新附件列表

**异常与边界**
- 路径为空：提示「路径不能为空」
- 路径冲突：提示「该路径已存在」

**验收标准**

| 验收项 | 验证方式 | 测试场景 | 边界条件 |
|-------|---------|---------|---------|
| 添加附件 | E2E | 填写路径和内容并保存 | - |
| 删除附件 | E2E | 删除附件 | - |
| 附件写入 | 单元测试 | 技能执行时检查文件是否写入 | - |

### 功能 5：技能动态写入

**功能目标/解决的问题**
任务执行时将技能文件写入工作目录，供 Claude Code 自动发现。

**前置条件**
- 技能已关联到执行任务的助手

**业务规则**
- 技能目录创建在 {workDir}/.claude/skills/
- SKILL.md 为技能主文件
- 附件文件按配置的路径写入
- 写入操作不消耗 Token（Claude Code 从文件系统读取）

**交互流程**
1. 任务执行模块准备工作目录
2. 获取助手关联的技能列表
3. 遍历技能列表，执行写入操作
4. 创建目录结构
5. 写入技能文件和附件
6. 启动 Claude Code CLI

**验收标准**

| 验收项 | 验证方式 | 测试场景 | 边界条件 |
|-------|---------|---------|---------|
| 目录创建 | 单元测试 | 检查 .claude/skills/ 目录 | - |
| SKILL.md 写入 | 单元测试 | 检查文件内容 | 特殊字符 |
| 附件写入 | 单元测试 | 检查附件文件 | 多文件 |
| 写入权限 | 单元测试 | 检查目录权限 | 只读目录 |

## 数据库设计

### 表结构

#### skill 表（技能）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 主键 |
| name | TEXT | NOT NULL, UNIQUE | 技能名称 |
| description | TEXT | | 技能描述 |
| content | TEXT | NOT NULL | 技能内容（SKILL.md） |
| created_at | TIMESTAMPTZ | NOT NULL | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | 更新时间 |

#### skill_file 表（技能附件）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 主键 |
| skill_id | UUID | NOT NULL, REFERENCES skill | 技能 ID |
| path | TEXT | NOT NULL | 文件路径（相对于技能目录） |
| content | TEXT | NOT NULL | 文件内容 |
| created_at | TIMESTAMPTZ | NOT NULL | 创建时间 |

**约束：** UNIQUE(skill_id, path)

#### agent_skill 表（助手-技能关联）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| agent_id | UUID | NOT NULL, REFERENCES agent | 助手 ID |
| skill_id | UUID | NOT NULL, REFERENCES skill | 技能 ID |
| position | INT | NOT NULL DEFAULT 0 | 排序位置 |

**主键：** (agent_id, skill_id)

### 索引

```sql
CREATE UNIQUE INDEX idx_skill_name ON skill(name);
CREATE INDEX idx_skill_file_skill ON skill_file(skill_id);
CREATE INDEX idx_agent_skill_agent ON agent_skill(agent_id);
CREATE INDEX idx_agent_skill_skill ON agent_skill(skill_id);
```

## 技术实现参考（Multica）

### 技能写入工作目录

```go
// server/internal/execenv/prepare.go
func (e *ExecEnv) WriteSkills(skills []Skill) error {
    skillsDir := filepath.Join(e.WorkDir, ".claude", "skills")
    if err := os.MkdirAll(skillsDir, 0755); err != nil {
        return err
    }

    for _, skill := range skills {
        skillDir := filepath.Join(skillsDir, skill.Name)
        if err := os.MkdirAll(skillDir, 0755); err != nil {
            return err
        }

        // 写入 SKILL.md
        skillFile := filepath.Join(skillDir, "SKILL.md")
        if err := os.WriteFile(skillFile, []byte(skill.Content), 0644); err != nil {
            return err
        }

        // 写入附件文件
        for _, file := range skill.Files {
            filePath := filepath.Join(skillDir, file.Path)
            if err := os.MkdirAll(filepath.Dir(filePath), 0755); err != nil {
                return err
            }
            if err := os.WriteFile(filePath, []byte(file.Content), 0644); err != nil {
                return err
            }
        }
    }
    return nil
}
```

### Claude Code 技能发现

Claude Code CLI 会自动扫描 `~/.claude/skills/` 目录，发现的技能会自动加载，不需要额外配置。技能发现：
- 扫描所有子目录
- 读取每个目录下的 `SKILL.md`
- 将内容作为上下文注入对话

### 本地技能兼容

本地技能（`~/.claude/skills/`）由 Claude Code CLI 直接管理，不写入数据库。Multica 管理的技能在执行时写入同一目录，实现共存。
