# 会话管理 PRD

> 状态：PRD 已确认
> 模块编号：02

## 1. 场景意图

### 1.1 业务背景与目标

会话是 forge 的**活动单元**（项目只是分类容器，见模块 01）。用户在项目下创建会话开展 AI 编程，会话复用 pi session（JSONL 存储）。v1 支持多会话并行执行与多窗口跨项目并排观察，让用户能同时盯多个会话的运行进度（对齐用户用 PowerShell 拆窗口看多会话的习惯）。

### 1.2 场景清单

| 场景 ID | 场景 | 业务价值 | 必须达成 | 明确不做 |
|---|---|---|---|---|
| SM-S01 | 创建会话 | 在项目下新建会话开展编程 | 项目下新建 pi session -> 进入会话 | 不预填任务/不自动跑 |
| SM-S02 | 切换会话 | 多会话间切换观察 | 切换只改当前观察视图，不影响其他会话执行 | 不暂停/销毁其他会话 |
| SM-S03 | 删除/重命名会话 | 管理会话生命周期 | 删除 pi session（确认）/ 改别名 | 删除无确认；软删除 |
| SM-S04 | 多会话并行 | 同时跑多个会话 | 多会话独立运行，UI 选中不影响执行 | 不硬限制并发数 |
| SM-S05 | 多窗口观察 | 跨项目并排看多个会话进度 | 应用内画布，窗口吸附，自由 resize | 不做单窗口分屏（方案 B） |
| SM-S06 | 会话列表双视角 | 项目/任务两种视角浏览会话（设计稿 `plan/logo-view-mockup.html` 已确认） | 任务视角平摊全部会话并标注归属项目；排序与项目视角同规则 | 不改会话归属与数据结构；不做任务级分组/汇总 |
| SM-S07 | 会话树缩放按钮 LOGO 化 | 品牌露出与缩放操作合一（zcode 风格） | 左上角按钮默认显方形 LOGO，hover 变缩放图标，点击折叠/展开会话树 | 不改缩放交互行为；LOGO 造型后续可整体重绘 |

### 1.3 边界与权限

- **不可接受方案**：UI 切换会话导致其他会话暂停或销毁；关闭窗口即删除会话；删除会话无确认；同一会话多窗口竞争同一流。
- **必须满足条件**：会话 = pi session（复用 pi 存储，不重造）；多会话并行执行；关闭窗口 = 摘除展示不删会话；窗口可跨项目观察任意会话。
- **角色与权限边界**：单用户；会话信任继承所属项目的信任状态（模块 01）；无 per-tool 审批（跟 pi 一致）。

### 1.4 已确认业务决策

- 会话 = pi session，复用 pi JSONL 存储（`<userData>/agent/sessions`），forge 不重造消息存储。
- 多会话并行执行：每个会话对应独立 pi `AgentSession` 实例，UI 切换不影响执行。
- 视窗 = **应用内画布**（单 BrowserWindow 内模拟多窗口，方案 A，原型 `plan/window-mode-mockup.html` 已验证交互）：关闭即摘展示不删会话、会话池拖拽开窗、自由 resize、**窗口吸附**（自定义 snap 逻辑，左/右/上/下/四角铺满，非 OS Aero Snap）、z-index 置顶、默认 4 窗格可自由组合。**非真 OS 窗口，不支持跨屏**（跨屏若需后续改真 BrowserWindow，属重写）。
- 跨项目会话观察：会话池列出所有项目的会话，可跨项目拖到画布并排。
- 项目信任继承：会话加载项目级 pi 资源受项目信任状态约束。
- 会话列表双视角（SM-S06）：项目视角=现状（按项目分组）；任务视角=平摊所有会话不分项目，行尾显示归属项目 tag（项目别名优先）；视角选择记忆在渲染层（localStorage），重启保持；任务视角下点会话=打开会话并隐式切换到所属项目（保持顶部「新会话」可用）。
- 收起全部/展开全部（SM-S06，仅项目视角）：无 边框 ghost 按钮，一个按钮两态——存在任一展开项目显示「收起全部」（对角双箭头内收），全部已收起显示「展开全部」（外扩）；折叠状态为 UI 态，与单项目折叠一致不落盘。
- 左上角缩放按钮 LOGO 化（SM-S07）：方形 LOGO 瓷片与缩放按钮合一，默认显瓷片、hover 交叉淡入缩放图标（折叠态箭头朝右）、点击行为不变；侧栏顶部「FORGE」渐变文字先隐藏，后续重设计仅替换瓷片节点。

> **已采用的常规默认项（无需确认）**：
> - 并发会话数不硬限制，UI 显示"运行中会话数"提示（烧 token 是用户选择）。
> - 多窗口交互细节（窗口吸附规则、z-index 置顶、自由 resize、4 窗格默认排列）属 UI 交互实现，在第 3 节详细设计展开，不作为技术决策。
> - 会话别名默认取 pi session 首条用户消息摘要，可编辑。
> - 会话列表按最近活动时间排序。

> **开发期风险与并发纪律（不阻塞 PRD 确认，已计入 overview）**：
> - TD-SM-01（源码分析结论，待运行时 spike 最终确认）：pi `AgentSession` 为实例类，无全局单例；每会话独立 `sessionManager`/`resourceLoader`/`modelRuntime`，事件总线 per-loader（`options.eventBus ?? createEventBus()`），扩展实例 per-loader。**架构上支持并发多实例**，前提纪律：(1) 每会话独立 `ResourceLoader`（不共享，否则事件总线/扩展串扰）；(2) forge 扩展**不得用模块级可变状态**存会话数据（jiti 按 path 缓存模块，模块全局量跨会话共享），须用实例字段或 session-keyed Map；(3) `ModelRuntime` 可共享（读多），并发鉴权刷新需验证。运行时 spike 脚本见 `plan/spike-multi-session.ts`（需先构建 pi）。
> - **SM-S04 vs SM-S05 解耦**：多窗口 UI（SM-S05）不依赖并发——即使并发受限，仍可多窗口观察多个会话（其一运行、其余看历史/状态）；仅 SM-S04（并行执行）需完整并发。故多窗口进 MVP 风险可控。
> - 多窗口状态同步：应用内多窗口看不同会话，会话输出流由 forge-core 统一管理，经 IPC 事件推送，窗口订阅对应会话（单 BrowserWindow，非多 BrowserWindow）。

## 3. 详细设计

### 3.1 模块概述与边界

- **业务目标**：会话的创建/切换/删除/重命名 + 多会话并行执行 + 多窗口跨项目并排观察。
- **核心职责**：会话生命周期管理（CRUD）、AgentSession 实例管理、会话输出流统一管理、多窗口画布交互。
- **核心业务对象**：会话（Session）= pi session + 元数据（别名、所属项目、最近活动时间、运行状态）。
- **涉及角色**：单用户。
- **前置条件**：项目已打开（信任按需，见模块 01）。
- **上下游与职责边界**：
  - 上游：模块 01 项目管理（会话归属于项目）。
  - 下游：模块 03 对话与消息（会话内发消息）；pi（session 存储、AgentSession）。
  - 数据边界：pi session 与消息存储归 pi；会话别名/归属等元数据由 forge 缓存；会话输出流由 forge-core 统一管理。

### 3.2 核心流程与状态

```
创建会话(cwd=项目目录) -> 空闲 -> 发消息(模块03) -> 运行中(流式输出) -> 完成/出错 -> 空闲
多会话: 各会话独立状态流转，互不影响
观察: 主视图单视图(点哪个看哪个) | 多窗口画布(拖会话开窗并排)
窗口: 拖会话到画布->开窗观察; 关闭->摘展示(会话不删); 重开->从会话池再拖
```

会话运行状态：`空闲` / `运行中` / `已完成` / `出错`。各会话独立流转。
观察状态：`主视图单视图`（默认，看选中会话）/ `多窗口画布`（增强，多会话并排）。两种可共存。

### 3.3 功能点

#### 功能点：SM-S01 创建会话

- **目标**：在当前项目下新建会话。
- **前置条件**：项目已打开。
- **业务规则**：点击"新建会话"仅进入**草稿输入态**（右侧出现输入框），此刻**不创建 pi session**；发送首条用户消息时才真正创建 pi session（cwd = 项目目录），并以**首条问题摘要**（截取首句，超 30 字加省略号）自动生成会话别名，随后在会话树出现带别名的标签。会话归属当前项目。
- **业务数据**：pi session id、别名、项目 id、创建时间、状态（空闲）。
- **交互与反馈**：
  - 项目工作区点"新建会话" -> 主视图显示草稿输入框并聚焦输入，会话树不新增标签。
  - 发送首条消息 -> forge 创建会话、生成别名，会话树新增带别名标签，输入内容进入对话流。
  - 未发首条消息不产生任何会话记录（切项目 / 关闭"新建"草稿即丢弃）。
  - **输入框项目选择器(v3.21)**:输入框底行左侧第一位 `📁 项目名 ▾`--草稿态=下拉选择归属项目(列已打开项目:别名优先+路径,条目悬停显示「移除」×,首点变红「确认」胶囊(与删除会话同款两阶段)、3s 内再点才移除,复用 PM-S03 移除语义(v3.32 改判:级联删除名下会话,源文件保留),条目仅此一个操作标,不显运行中状态点/当前 ✓;条目排序=最近使用置顶(MRU,v3.45 用户裁定:触发点仅两个=新建项目、创建会话成功;重复使用也置顶,其余相对顺序不变;纯下拉选中不改序;与项目树拖拽序无关;未记录的按后端序排后,重启保持;移除项目时同步清除其序号记录);底部“打开项目…”直接弹系统目录选择器（不弹项目弹窗，选中即注册，取消无操作；v3.48：注册成功后自动切换为当前项目，草稿保留）；选中=切换当前项目，草稿保留）；会话中=同式样只读展示归属(不弹浮窗、无▾,归属不可更换)。
  - 点"新建会话"默认选中**项目选择器列表第一项**（v3.38 用户裁定：仅默认高亮/归属取第一项，序即 MRU 最近使用；选中后仍可在输入框底行改；项目工作区行内"新建会话"固定归属所在项目）；禁用条件为"无任何已打开项目"。
- **权限边界**：会话信任继承所属项目。
- **合法/非法状态流转**：草稿输入态 -> （发送首条消息）空闲（合法）；草稿输入态 -> 丢弃（离开不创建，合法）。
- **异常与边界**：首条消息发送时 pi session 创建失败 -> 提示原因，不创建、不入树，草稿保留可重试。
- **数据一致性与幂等**：会话存储交 pi，元数据 forge 缓存；未发消息不落库；重复点击"新建会话"各自进入独立草稿态。
- **跨模块影响**：创建会话联动模块 03，首条消息自动命名由 forge-core `onFirstUserMessage` 完成并经 `session.updated` 事件同步 UI 会话树；标题仅取消息首行，附件路径行（附件统一给路径后随正文换行追加）不进标题。

#### 功能点：SM-S02 切换会话

- **目标**：多会话间切换观察，不影响其他会话执行。
- **前置条件**：存在 ≥2 个会话。
- **业务规则**：切换 = 改主视图订阅的会话输出流；不暂停/销毁其他会话；其他运行中会话继续后台执行（TD-SM-01）。
- **业务数据**：当前选中会话 id 切换；其他会话状态不变。
- **交互与反馈**：会话列表点会话项 -> 主视图切换显示该会话最新内容（含运行中实时输出）。
- **权限边界**：无。
- **合法/非法状态流转**：选中 A -> 选中 B（合法）；切换时 A 运行中 -> A 继续运行（合法）。
- **异常与边界**：切换到已被删除的会话 -> 列表移除该项。
- **数据一致性与幂等**：每会话输出流独立，切换只改订阅，不重放/丢失消息。
- **跨模块影响**：模块 03 对话流切换。

#### 功能点：SM-S03 删除/重命名会话

- **目标**：管理会话生命周期。
- **前置条件**：会话存在。
- **业务规则**：
  - 删除 = 删 pi session（不可逆，TD-SM-05 A），二次确认弹窗明确"将永久删除该会话所有消息"。
  - 重命名 = 改 forge 侧别名，不改 pi session 内容。
  - 删除运行中会话 -> 先停止其 AgentSession 再删。
- **业务数据**：删除移除 pi session + forge 元数据；重命名只改别名。
- **交互与反馈**：会话项右键"删除" -> 确认弹窗 -> 确认后删除；"重命名" -> 内联编辑别名。
- **权限边界**：单用户；删除不可逆需二次确认。
- **合法/非法状态流转**：存在 -> 已删除（合法，不可逆）；运行中 -> 先停止再删除（合法）。
- **异常与边界**：删除失败 -> 提示，会话保留；删除运行中会话必须先停止。
- **数据一致性与幂等**：删 pi session 不可逆；重命名幂等。
- **跨模块影响**：删除会话时关闭其观察窗口（若在画布上）。

#### 功能点：SM-S04 多会话并行

- **目标**：多个会话同时运行，互不影响。
- **前置条件**：多个会话存在。
- **业务规则**：每会话独立 pi AgentSession（TD-SM-01 A）；执行与输出流由 forge-core 统一管理，与窗口解耦（TD-SM-04）；UI 选中/切换不影响其他会话执行；不硬限制并发数，UI 显示"运行中会话数"。
- **业务数据**：各会话独立状态（空闲/运行中/完成/出错）。
- **交互与反馈**：会话列表显示各会话实时状态；主视图看选中会话；多窗口可同时观察多个并行会话。
- **权限边界**：无。
- **合法/非法状态流转**：各会话独立流转，无共享可变状态。
- **异常与边界**：某会话出错不影响其他会话；资源不足时提示但不强制停止。
- **数据一致性与幂等**：会话间状态独立，无竞争。
- **跨模块影响**：模块 03 对话流；pi 事件 -> CanonicalEvent 映射（forge-core）。

#### 功能点：SM-S05 多窗口观察

- **目标**：跨项目并排观察多个会话的运行进度。
- **前置条件**：多个会话存在（可跨项目）。
- **业务规则**：
  - 多独立窗口画布（TD-SM-02 A）：每窗口观察一个会话。
  - 一会话一窗口（TD-SM-04 A）：同一会话不重复开窗。
  - 跨项目会话池（TD-SM-03 A）：会话池列出所有项目会话，可跨项目拖到画布。forge 自行遍历 `<userData>/agent/sessions/` 解码各 cwd 枚举跨项目会话（pi 无此 API）。
  - 关闭窗口 = 摘除展示，不删会话。
  - 窗口吸附（自定义 snap，非 OS Aero Snap）：拖窗口到画布左/右/上/下边缘铺满半区，拖到四角铺满象限；拖拽时显示预览框。
  - 自由 resize：拖窗口右下角调整大小（最小尺寸限制）。
  - z-index 置顶：点/拖/resize 的窗口自动提到最上层。
  - 默认 4 窗格排列，可自由组合。
- **业务数据**：窗口-会话绑定关系（一会话一窗口）；窗口布局状态（位置/大小）。
- **交互与反馈**：
  - 从会话池拖会话到画布 -> 在落点开窗；拖到边缘/角 -> 预览高亮 -> 松手铺满。
  - 拖窗口标题栏移动；拖右下角 resize。
  - 点窗口红圆点关闭 -> 窗口消失，会话回会话池。
  - "4 窗格"按钮 -> 可见窗口一键严丝合缝排列。
- **权限边界**：无。
- **合法/非法状态流转**：会话在画布 -> 关闭 -> 会话池（可重开）；同一会话重复开窗（非法，拒绝/聚焦已有窗口）。
- **异常与边界**：会话被删除 -> 其观察窗口自动关闭；窗口崩溃 -> 会话状态在 forge-core 保留，可重开。
- **数据一致性与幂等**：窗口是观察口，会话输出在 forge-core；多窗口看不同会话无流竞争。
- **跨模块影响**：模块 03 对话流（窗口内对话）；窗口状态由 forge-core 统一，窗口崩溃可恢复。

#### 功能点：SM-S06 会话列表双视角（项目/任务）

- **目标**：提供项目视角（现状）与任务视角两种会话列表浏览方式。
- **前置条件**：无（空态各自提示：项目视角「暂无项目」，任务视角「暂无会话」）。
- **业务规则**：
  - 项目视角 = 现状：按项目分组、项目拖拽排序、单项目折叠、超 5 条截断展开。
  - 任务视角 = 平摊所有会话、不分项目；行尾显示归属项目 tag（项目别名优先，无别名取路径末段，超长省略）；默认显示前 20 条（同排序规则），多余折叠为「展开显示 N 个」（与项目视角同交互）；不做拖拽排序。
  - 排序规则两视角一致：运行中会话置顶且完成后保留位置（激活序，同现有 ProjectTree 规则），从未激活的保持后端原序（稳定排序）。
  - 点击会话行为一致：打开会话；任务视角下隐式切换到所属项目（保持顶部「新会话」按钮可用）。
  - 会话行能力一致：状态点、重命名（双击）、删除（两阶段确认）、拖拽到多窗口画布、已开窗灰态。
  - 视角选择记忆在渲染层（localStorage），重启保持。
  - 多窗口配套：「返回多窗口」聚焦行显示归属项目 pill（窗口标题行项目 pill 现状已有，保留统一）。

- **交互与反馈**：「项目 / 任务」分段开关（侧栏顶部，替代原静态「项目」标签）；任务视角行尾项目 tag；收起/展开全部按钮 hover 淡底色。分段开关选中态为滑动指示胶囊（水滴果冻过渡：左右两边各自动画，先行边带回弹、另一边延迟 70ms 追随），胶囊几何按 **active 按钮实测**贴合（中英文文案不等宽均须贴合），且为渲染层实测值不落盘——凡分段开关自身尺寸发生变化（首帧挂载、侧栏折叠/展开的宽度过渡、语言切换）都必须重贴，否则胶囊会残留按旧宽度算出的几何而被拉长变形。

- **合法/非法状态流转**：项目视角 ⇄ 任务视角随时切换（合法，列表数据同源）；任务视角下会话被删除 → 列表移除。

- **数据一致性与幂等**：两视角同源渲染，无独立数据副本；重复切换无副作用。
- **跨模块影响**：模块 01（项目别名用于 tag）；多窗口画布（聚焦行项目 pill）。

### 3.4 页面承载

- **页面路径与访问权限**：项目工作区（打开项目后进入，无额外权限）。
- **页面结构**：
```
项目工作区
┌──────────┬─────────────────────────┐
│ 会话池    │ 主视图(单视图:看选中会话)  │
│ (跨项目)  │   或 多窗口画布            │
│ ▸项目A    │ ┌────────┬────────┐       │
│  会话A ● │ │ 会话A  │ 会话B  │ (Snap)│
│  会话B   │ ├────────┼────────┤       │
│ ▸项目B    │ │ 会话C  │        │       │
│  会话C   │ └────────┴────────┘       │
│ [新建]    │                          │
└──────────┴─────────────────────────┘
```
- **操作入口、按钮和链接**："新建会话"（创建）；左上角 LOGO 瓷片缩放按钮（折叠/展开会话树，hover 显缩放图标）；侧栏顶部"项目/任务"分段开关（视角切换）；"收起/展开全部"按钮（项目视角，无 边框 ghost）；打开项目按钮；会话池项拖拽（开窗）；会话项点击（主视图切换）；会话项双击（重命名）；会话项 hover 删除（两阶段确认）；窗口标题栏（移动）；窗口右下角（resize）；窗口红圆点（关闭）；"4 窗格"按钮（排列）。
- **表单字段与业务校验**：重命名内联编辑（非空，默认摘要）。
- **弹窗、loading、成功/失败反馈**：
  - 删除确认弹窗：触发=点删除；内容="将永久删除该会话所有消息，不可恢复"；操作=确认/取消。
  - 窗口吸附预览：拖拽到边缘/角时显示半透明高亮框指示将铺满区域。
  - 创建成功=主视图显示；删除成功=列表移除+窗口关闭；拖拽开窗=窗口出现。
- **失败时的上下文和数据保留**：操作失败不清空会话状态；窗口崩溃后重开恢复会话内容。

### 3.5 非功能要求

- **性能与容量**：多会话并行典型 ≤10 个，每会话流式输出端到端延迟 < 100ms；窗口拖拽/resize 60fps；会话池渲染 < 200ms。
- **安全与审计**：删除不可逆，二次确认；无 per-tool 审批（跟 pi 一致）。
- **可用性与降级**：单会话出错不影响其他；窗口崩溃不丢会话状态；pi 多 AgentSession 不可用时降级为单活动会话。
- **可观测性**：会话运行状态、运行中会话数实时可见；会话生命周期事件记日志。
- **兼容性**：窗口-会话绑定与布局状态由 forge-core 统一，支持窗口崩溃恢复。
