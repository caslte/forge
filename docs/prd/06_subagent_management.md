# 子 Agent 管理 PRD

> 状态：PRD 已确认

## 1. 场景意图

### 1.1 业务背景与目标

forge 会话中，主 agent 可通过子 agent 能力（pi 的 `@tintinweb/pi-subagents` 扩展）派生独立会话执行研究、抓取、批量修改等长任务。子 agent 默认**后台运行**：派生调用立即返回，主 agent 本轮随即结束。

当前 forge 存在两个缺口：

1. **状态误判**：主会话状态仅以"主 agent 本轮结束"为完成判据。派生后台子 agent 后主会话立即显示"已完成"，用户误以为回复结束，实际子 agent 仍在运行，结果尚未产生。
2. **完全不可见**：forge 无法看到会话内活跃/已完成的子 agent（类型、描述、状态、耗时），更无法干预（如终止卡住的子 agent）。UI 仅有占位类型，无任何功能。

本模块目标：forge 感知子 agent 生命周期，使主会话状态真实反映"含后台工作的整体进行状态"，并提供轻量监控与终止能力。

### 1.2 场景清单

| 场景 ID | 场景 | 业务价值 | 必须达成 | 明确不做 |
|---|---|---|---|---|
| SA-S01 | 主会话状态联动 | 用户不被"假完成"误导，可持续监控 | 存在运行中子 agent 时主会话保持"运行中"；全部子 agent 结束（完成/失败/终止）后主会话才转"已完成" | 不阻止主 agent 本轮文本先输出完（文字照常流式，仅状态判定联动） |
| SA-S02 | 子 agent 动态监控 | 一眼看清会话内派生了什么、跑到哪了 | 会话视图内展示子 agent：Tab 栏（状态点+名称）与结果视图（状态、实时耗时、result 全文、Token 用量）；状态实时刷新 | 不做子 agent 内部对话的实时逐 token 流式查看（v1 仅摘要级信息）；不做左侧项目树"子 Agent (N)"分组（v1 不加，后续迭代可议） |

### 1.3 边界与权限

- **不可接受方案**：forge fork/修改 pi-subagents 扩展源码；forge 重造子 agent 调度引擎。
- **必须满足条件**：子 agent 生命周期感知为**事件驱动**（不轮询会话文件）；主会话状态判定与子 agent 计数联动必须可降级（子 agent 信号丢失时不得永久卡在"运行中"，超时兜底自动放行）；未安装 pi-subagents 扩展的环境功能静默不启用、无坏入口。
- **角色与权限边界**：单用户本地应用，无角色区分；终止操作仅作用于当前会话派生的子 agent。

### 已采用的常规默认项

- 子 agent 状态文案：排队中 / 运行中 / 已完成 / 失败 / 已终止（映射扩展记录状态 queued/running/completed/error/aborted|stopped）。
- Tab 栏运行中子 agent 的关闭按钮禁用（与 ai-coding 一致：运行中不可关闭 Tab，只能终止或等其结束）；已完成/失败 Tab 可单个关闭，"清除已完成"批量清除。
- 停止按钮级联终止不需要二次确认（与现有停止交互一致）；面板内单个子 agent 终止需二次确认（不可逆操作）。
- 事件与状态变更记日志（可观测性沿用模块 02/04 规则）。

## 3. 详细设计

### 3.1 模块概述与边界

- **业务目标**：forge 感知子 agent 生命周期；主会话状态反映含后台工作的整体状态；提供 Tab 监控与终止。
- **核心职责**：子 agent 事件接入与按会话归组、主会话状态联动判定、Tab 栏与结果视图渲染、终止（级联+单个）、完成通知渲染保障。
- **核心业务对象**：子 agent（Subagent）= 扩展派生 ID + 类型 + 描述 + 状态 + 起止时间 + result 摘要 + Token 用量；归属唯一主会话。
- **涉及角色**：单用户本地应用，无角色区分。
- **前置条件**：目标会话由 forge 创建并持有 AgentSession；环境加载了 pi-subagents 扩展（未加载则模块静默降级，见 SA-F08）。
- **上下游与职责边界**：
  - 上游：模块 02 会话管理（会话创建/删除时联动清理）、模块 03 对话（完成通知作为消息流一部分渲染）。
  - 下游：pi-subagents 扩展（事件源与执行体）；forge 不 fork、不重造调度。
  - 数据边界：子 agent 运行态归 forge 内存（按会话隔离）；子 agent 会话与结果归 pi 扩展持久化；forge 不持久化子 agent 列表（TD-SA-05）。

### 3.2 核心流程与状态

```
主 agent 调 Agent 工具(后台) → 扩展派生子 agent
  → subagents:created → subagents:started（排队→运行中）
  → 主 agent 本轮结束，但仍有活跃子 agent → 主会话保持"运行中"（SA-F02）
  → subagents:completed / subagents:failed（→已完成/失败，结果通知进消息流）
  → 全部结束 → 主会话转"已完成"（或立即被用户继续对话进入新一轮）
用户终止：停止按钮 → 级联终止主 agent 本轮 + 全部活跃子 agent（已终止）
        面板单个终止 → 该子 agent 已终止
```

子 agent 状态机：`排队中 → 运行中 → 已完成 / 失败 / 已终止`。运行中 → 其他任意终态合法；终态 → 运行中非法（resume 场景由扩展生成新记录，forge 按新 ID 处理）。

主会话状态机扩展（模块 02 状态基础上）：`空闲 / 运行中 / 已完成 / 出错` 中，"已完成"的进入条件增加"活跃子 agent 计数为 0"。

### 3.3 功能点

#### 功能点：SA-F01 子 agent 事件接入与按会话归组

- **目标**：forge 实时感知每个会话派生的子 agent 生命周期。
- **前置条件**：会话已创建；环境加载了 pi-subagents 扩展。
- **业务规则**：forge 创建 AgentSession 时注入共享事件总线并订阅 `subagents:created / started / completed / failed` 生命周期事件；事件按发生会话归组到该会话的内存态列表（TD-SA-05），列表项含：扩展子 agent ID、类型、描述、状态、开始时间、结束时间、result 摘要、Token 用量。同一 ID 的事件按幂等合并（后到字段覆盖，终态不可逆）。
- **业务数据**：子 agent ID、类型、描述、状态、startedAt、finishedAt、result、Token 用量。
- **交互与反馈**：不直接面向用户；数据驱动 SA-F03/SA-F04。
- **权限边界**：仅本会话数据，无跨会话访问。
- **合法/非法状态流转**：排队中→运行中→终态（合法）；终态→运行中（非法，忽略）。
- **异常与边界**：事件乱序（completed 先于 started 到达）按最终状态收敛；子 agent 完成通知晚于会话删除 → 事件丢弃（会话已不存在）。
- **数据一致性与幂等**：同 ID 重复事件幂等；UI 最终一致（以扩展最终状态为准）。
- **跨模块影响**：为 SA-F02 提供活跃计数，为 SA-F03/04 提供展示数据。

#### 功能点：SA-F02 主会话状态联动

- **目标**：主会话状态真实反映"含后台工作的整体进行状态"。
- **前置条件**：SA-F01 事件接入正常。
- **业务规则**：主会话"已完成"判定 = 主 agent 本轮结束 **且** 该会话活跃子 agent（排队中/运行中）计数为 0。存在活跃子 agent 时主会话保持"运行中"（会话树状态点、输入框状态、思考指示联动模块 02/03 现有语义）。主 agent 本轮结束时若仍有活跃子 agent，主 agent 的文字输出照常完成渲染（仅状态判定延后）。
- **业务数据**：主会话状态、活跃子 agent 计数。
- **交互与反馈**：会话列表状态点持续"运行中"脉动；切回该会话可见 Tab 栏与计时中的子 agent。
- **权限边界**：不涉及。
- **合法/非法状态流转**：运行中（主 agent 结束但有活跃子 agent）→ 已完成（计数归零）（合法）；已完成 → 运行中（非法，新对话走新一轮状态）。
- **异常与边界**：**超时兜底**——活跃子 agent 计数非零但连续 30 分钟无任何子 agent 事件更新，判定信号丢失，自动放行置"已完成"并记日志（TD-SA-02）；应用关闭时会话终止，无残留状态。
- **数据一致性与幂等**：状态联动判定可重复执行，结果幂等。
- **跨模块影响**：改变模块 02 会话状态树展示与模块 03 输入框可发信状态（运行中仍可排队/停止按现状）。

#### 功能点：SA-F03 子 agent Tab 栏

- **目标**：一眼看清会话内子 agent 及状态，可切换查看。
- **前置条件**：当前会话存在至少一个子 agent 记录（运行期内存态）。
- **业务规则**：输入框上方渲染水平 Tab 栏：固定"主会话"Tab + 每个子 agent 一个 Tab（状态点 + 描述名）；右侧"清除已完成"按钮（仅存在已完成/失败/已终止记录时可用，批量移除终态记录）。无子 agent 时整条 Tab 栏不渲染。运行中 Tab 不显示关闭钮（禁用）；已完成/失败/已终止 Tab 显示关闭钮可单个移除。同一会话内 Tab 顺序：运行中在前，终态按结束时间倒序。
- **业务数据**：同 SA-F01。
- **交互与反馈**：状态点实时变色（排队/运行中黄、完成绿、失败红、终止灰）；当前激活 Tab 高亮，默认停在"主会话"；点子 agent Tab 消息区切换结果视图（SA-F04），点"主会话"切回消息流；切换会话各自保留各自的激活 Tab 与列表（TD-SA-05）。
- **权限边界**：不涉及。
- **合法/非法状态流转**：列表空 ↔ 非空（Tab 栏出现/消失）（合法）；移除运行中 Tab（非法，禁用）。
- **异常与边界**：子 agent 数量多时 Tab 横向滚动；描述名过长截断（悬停 title 全文）；多窗口模式下每个窗口独立渲染所属会话的 Tab 栏，行为与单视图一致（TD-SA-04）。
- **数据一致性与幂等**：状态更新幂等；移除仅影响 UI 列表，不影响扩展运行。
- **跨模块影响**：ConversationView / MultiWindowConversation 两套会话视图同步改造，保持行为一致（项目纪律）。

#### 功能点：SA-F04 子 agent 结果视图

- **目标**：查看单个子 agent 的详情与结果。
- **前置条件**：Tab 栏存在且用户点选某子 agent Tab。

#### 功能点：SA-F05 停止按钮级联终止

- **目标**：一键"整件事都别做了"。
- **前置条件**：会话处于运行中（主 agent 本轮进行中或存在活跃子 agent），输入框停止按钮可用。
- **业务规则**：点击停止 = 终止主 agent 当前轮次（现有 abort 语义，保留已生成内容）+ 经扩展 RPC 逐个终止该会话全部活跃（排队中/运行中）子 agent；被终止子 agent 状态置"已终止"，Tab 与结果视图同步更新；主会话状态转"已完成"。
- **业务数据**：被终止子 agent ID 列表。
- **交互与反馈**：与现有停止一致即时反馈；被终止 Tab 状态点变灰"已终止"。
- **权限边界**：仅作用于当前会话派生的子 agent。
- **合法/非法状态流转**：活跃 → 已终止（合法）；已终止 → 运行中（非法）。
- **异常与边界**：级联逐个终止部分失败时重试一次，仍失败记日志并在 Tab 上保留原状态（不静默丢）；无活跃子 agent 时行为与现有停止完全一致（纯 abort）。
- **数据一致性与幂等**：重复点击停止幂等（已终止的跳过）。
- **跨模块影响**：模块 03 停止交互语义扩展；模块 02 会话状态联动（AC-SA-005 同规则收敛）。

### 3.4 页面承载

- **页面路径与访问权限**：会话视图内（单视图 ConversationView + 多窗口 MultiWindowConversation），无独立路由；本地单用户无权限控制。
- **页面结构**：

```
┌─ 消息区（主会话 Tab 激活时显示消息流；子 agent Tab 激活时显示结果视图，v-show 互斥）─┐
├─ Tab 栏（有子 agent 才渲染）──────────────────────────────────────┤
│ │ 主会话 │ ●子agentA ×(禁) │ ✓子agentB × │ … │ [清除已完成]        │
├─ 输入区（现有 InstructionInput，不改动布局）────────────────────────┤
```

结果视图：

```
┌──────────────────────────────────────────────┐
│ 🤖 描述名  [类型徽标] ●状态文字 · 实时耗时 [终止] │
├──────────────────────────────────────────────┤
│ result 全文（内部滚动）/ 运行中占位提示          │
│ Token 用量（终态显示）                          │
└──────────────────────────────────────────────┘
```

- **操作入口、按钮和链接**：Tab 切换（点 Tab）；单个关闭（终态 Tab 的 ×）；清除已完成（批量）；终止（结果视图头部，二次确认）；停止（沿用输入框停止按钮，新增级联语义）。
- **表单字段与业务校验**：无表单。
- **弹窗、loading、成功/失败反馈**：单个终止二次确认弹窗；终止 RPC 失败 toast 报错；运行中耗时每秒刷新。
- **失败时的上下文和数据保留**：终止失败状态不变可重试；Tab 移除仅删 UI 记录不影响消息流通知；切换 Tab/会话不丢数据（内存态）。

### 3.5 非功能要求

- **性能与容量（量化）**：子 agent 事件从扩展发出到 UI 状态更新 ≤ 500ms（进程内事件传递 + IPC，正常负载）；同一会话并发子 agent 支撑 ≥ 10 个（扩展默认并发上限）；结果视图 result 全文 ≤ 1MB 内部滚动渲染不卡顿；耗时刷新每秒 1 次，不引发消息流重排。
- **安全与审计**：终止操作仅限本会话子 agent；子 agent 生命周期事件（ID、类型、状态变迁、耗时、终止发起方）记日志。
- **可用性与降级**：扩展缺失/加载失败静默降级（SA-F08）；事件流中断由 30 分钟超时兜底收敛主会话状态（AC-SA-006）；单会话子 agent 异常不影响其他会话。
- **可观测性**：状态联动判定、兜底触发、级联终止结果均记日志；Tab 状态与扩展记录最终一致（偏差可由日志追溯）。
- **兼容性**：无子 agent 的既有会话行为零变化（AC-SA-009/018/024 回归保障）；单视图与多窗口行为一致（AC-SA-012）。
