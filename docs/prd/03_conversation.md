# 对话与消息 PRD

> 状态：PRD 已确认（含扩展 CV-S06 会话历史导航）
> 模块编号：03
> 扩展说明：CV-S06 由用户需求「增加一个这种左侧的用户会话历史，点击可以定位，然后可以看到历史的对话浮窗」（附 ZCode 客户端参考图）发起。用户裁定**不单独设模块**，并入本模块、放主会话（对话区）一侧；交互形态随之调整为**会话内提问时间线**（原独立模块 07 方案撤销）。扩展章节已随用户确认（2026-08-29）。

## 1. 场景意图

### 1.1 业务背景与目标

会话内的对话编程是 forge 的核心交互：用户发送消息，pi `AgentSession` 处理并流式返回响应（可能含工具调用，工具执行展示见模块 04）。forge 负责消息的流式增量渲染（Markdown / 代码高亮 / Mermaid）与消息历史加载，让用户在会话中获得实时、富文本的编程对话体验。

### 1.2 场景清单

| 场景 ID | 场景 | 业务价值 | 必须达成 | 明确不做 |
|---|---|---|---|---|
| CV-S01 | 发送消息 | 用户向会话发消息触发 AI 处理 | 输入消息 -> 发送 -> 进入流式响应 | 不发送空消息；不发送队列 |
| CV-S02 | 流式响应 | 实时显示 AI 回复 | token 增量流式渲染，不卡顿 | 不等全部生成再显示 |
| CV-S03 | 富文本渲染 | 安全展示 Markdown/代码/Mermaid | Markdown + 代码高亮 + Mermaid 渲染 | 不渲染任意 HTML（XSS 风险） |
| CV-S04 | 取消响应 | 中断正在跑的响应 | 取消 -> 停止当前处理，保留已生成内容 | 取消不丢弃已生成内容 |
| CV-S05 | 消息历史 | 打开会话加载已有消息 | 加载 pi session 历史消息正确展示 | 不重复/不丢失历史消息 |
| CV-S06 | 会话历史导航（扩展） | 长对话快速回看与回跳 | 对话区左缘提问时间线：列出当前会话全部用户消息；点击定位到该消息；hover 浮窗预览该轮对话 | 不做跨会话历史列表；不做搜索/收藏/置顶；浮窗不渲染 Markdown/图片 |
| CV-S07 | 上下文压缩 | 长对话接近上下文上限时释放空间且过程可感知 | 手动压缩按钮可用并有明确结果反馈；运行时自动压缩完成后界面历史同步刷新并提示；压缩失败一律可见上报 | 不自定义压缩策略/阈值（沿用运行时默认）；不编辑压缩摘要；不做压缩历史回退 |

### 1.3 边界与权限

- **不可接受方案**：渲染任意 HTML（XSS）；取消时丢弃已生成内容；流式卡顿/阻塞 UI；历史消息丢失或重复。（扩展 CV-S06）点击定位后被流式自动滚底冲走；浮窗渲染富文本引入 XSS 面。
- **必须满足条件**：消息 = pi session 消息（复用 pi 存储）；流式增量渲染；Markdown 安全渲染（白名单）；取消保留已生成内容。（扩展 CV-S06）时间线/浮窗均为纯文本展示（文本插值默认转义）；定位进入回看模式不被流式打断。
- **角色与权限边界**：单用户；无 per-tool 审批（跟 pi 一致）；消息内容信任由 pi 处理，forge 仅渲染。

### 1.4 已确认业务决策

- 消息复用 pi session JSONL 存储，forge 不重造消息存储（对齐模块 02）。
- 流式响应：pi 事件经 forge-core 映射为 `CanonicalEvent`，经传输无关接口增量推送前端（桌面 IPC 事件 / headless SSE）。
- 富文本渲染复用 ai-coding 前端（marked / prismjs / mermaid）。
- 取消 = 停止 `AgentSession` 当前处理，保留已生成内容（跟 pi abort 语义一致）。
- （扩展 CV-S06）时间线与浮窗由**当前会话已加载的消息流**派生，零新增接口、零新增存储；仅作用于主会话消息流（子 agent 结果视图不渲染时间线，画布小窗后续迭代）。
- （扩展 CV-S06）交互参考 ZCode 客户端会话历史浮窗；用户裁定并入本模块主会话侧，不单独设模块。

## 3. 详细设计

### 3.1 模块概述与边界

- **业务目标**：会话内对话编程，覆盖发送、流式响应、富文本渲染、取消、历史加载。
- **核心职责**：消息发送、流式接收与增量渲染、Markdown 安全渲染、取消、历史消息加载。
- **核心业务对象**：消息（Message）= pi session 消息（角色 user/assistant/tool，内容、时间）。
- **涉及角色**：单用户。
- **前置条件**：会话已创建（模块 02）；provider 已配置（模块 05，未配置则提示）。
- **上下游与职责边界**：
  - 上游：模块 02 会话管理（会话存在）。
  - 下游：模块 04 工具执行展示（工具消息卡片在对话区穿插）；pi（AgentSession、session 存储）。
  - 数据边界：消息存储归 pi；渲染状态归 forge 前端。

### 3.2 核心流程与状态

```
发送消息 -> AgentSession 处理 -> 流式响应(token 增量) -> 渲染 -> 完成
取消: 运行中 -> 停止处理 + 保留已生成 -> 空闲(可继续发新消息)
历史: 打开会话 -> 加载 pi session 消息 -> 渲染 -> 滚到最新
```

会话执行状态：`空闲` -> `运行中(流式)` -> `已完成` / `已取消` -> `空闲`。

### 3.3 功能点

#### 功能点：CV-S01 发送消息

- **目标**：用户向会话发送消息触发 AI 处理。
- **前置条件**：会话存在；provider 已配置。
- **业务规则**：消息非空才可发送；发送后进入流式响应；消息写入 pi session。
- **业务数据**：消息内容、角色 user、时间戳。
- **交互与反馈**：输入框输入 -> Enter 发送 -> 消息追加到对话区 -> 进入流式响应。provider 未配置时提示先配置而非崩溃。
- **权限边界**：无审批（跟 pi 一致）。
- **合法/非法状态流转**：空闲 -> 运行中（合法）；运行中再发送（非法，需排队或禁用，v1 禁用发送按钮）。
- **异常与边界**：provider 未配置 -> 提示配置；发送失败 -> 提示，消息可重发。
- **数据一致性与幂等**：消息写 pi session；重复点击发送在运行中被禁用避免重复。
- **跨模块影响**：触发模块 04 工具执行展示（若 AI 调工具）。

|---|---|---|---|---|---|

| AC-CV-002 | 空消息不可发送（发送按钮禁用） | unit | 边界 | 输入校验 | 空输入 |
| AC-CV-003 | provider 未配置时发送操作提示配置而非崩溃 | E2E | 异常 | 可用性 | 无 provider |

#### 功能点：CV-S02 流式响应

- **目标**：实时显示 AI 回复。
- **前置条件**：消息已发送，AgentSession 处理中。
- **业务规则**：token 增量流式渲染（TD-CV-01 A）；pi 事件 -> CanonicalEvent -> 增量事件推送（桌面 IPC 事件 / headless SSE）-> 前端增量 DOM 更新；不阻塞 UI。
- **业务数据**：assistant 消息增量内容。
- **交互与反馈**：流式 token 逐字显示在对话区；运行中显示"运行中"状态。
- **权限边界**：无。
- **合法/非法状态流转**：运行中 -> 已完成（合法）；运行中 -> 已取消（合法）。
- **异常与边界**：流中断 -> 标记中断，保留已收内容，可重试/继续。
- **数据一致性与幂等****：增量追加不重复；最终内容与 pi session 一致。
- **跨模块影响**：工具消息穿插展示（模块 04）。

验收标准：

| AC ID | 验收事实 | 验证层级 | 场景 | 风险维度 | 边界条件 |
|---|---|---|---|---|---|
| AC-CV-004 | AI 回复流式增量显示，UI 不卡顿 | E2E | 正常流程 | 性能 | 长响应 |
| AC-CV-005 | 流式中断时保留已收内容并标记中断 | E2E | 异常 | 状态/一致性 | 网络中断 |

#### 功能点：CV-S03 富文本渲染

- **目标**：安全展示 Markdown / 代码 / Mermaid。
- **前置条件**：消息内容存在。
- **业务规则**：
  - Markdown 渲染（标题/列表/链接/引用/表格）。
  - 代码高亮（prismjs，自动识别语言 + 手动指定）。
  - Mermaid 图客户端渲染。
  - 白名单安全渲染（TD-CV-02 A）：禁原生 HTML，转义/剔除 `<script>`、`onerror` 等危险内容。
- **业务数据**：渲染后 DOM。
- **交互与反馈**：消息渲染为富文本；代码块可复制；Mermaid 渲染为图。
- **权限边界**：白名单安全是硬约束，不可绕过。
- **合法/非法状态流转**：不适用。
- **异常与边界**：Mermaid 语法错误 -> 显示错误提示 + 源码；代码语言不支持 -> 纯文本显示。
- **数据一致性与幂等**：相同内容渲染一致。
- **跨模块影响**：模块 04 工具结果内容也走此渲染。

#### 功能点：CV-S04 取消响应

- **目标**：中断正在跑的响应。
- **前置条件**：响应运行中。
- **业务规则**：取消 = 停止 AgentSession 当前处理（TD-CV-03 A）；保留已生成内容；取消后可发新消息。
- **业务数据**：assistant 消息保留已生成部分，标记为已取消。
- **交互与反馈**：运行中显示"取消"按钮 -> 点击 -> 停止 -> 已生成内容保留显示，状态变空闲。
- **权限边界**：无。
- **合法/非法状态流转**：运行中 -> 已取消(保留) -> 空闲（合法）；取消丢弃已生成（非法）。
- **异常与边界**：取消失败 -> 提示，可重试取消。
- **数据一致性与幂等**：已生成内容不丢失；重复取消无副作用。
- **跨模块影响**：取消时进行中的工具执行处理（模块 04）。

- **业务数据**：历史消息列表。
- **交互与反馈**：打开会话 -> 加载历史 -> 渲染显示 -> 滚动到最新。
- **权限边界**：无。
- **合法/非法状态流转**：不适用。
- **异常与边界**：历史加载失败 -> 提示，可重试。
- **数据一致性与幂等**：不重复不丢失；多次打开同一会话结果一致。
- **跨模块影响**：工具历史消息走模块 04 卡片展示。

#### 功能点：CV-S06 会话历史导航（扩展）

- **目标**：在主会话对话区左缘提供提问时间线，用户不滚动即可纵览对话结构，点击回跳、hover 预览。
- **前置条件**：会话已打开且消息流已加载（CV-S05）；主会话 Tab 激活（非子 agent 结果视图）。
- **业务规则**：
  - 时间线由当前已加载消息流派生：每条用户消息一个条目，按时间正序排列，条目为**简化短横条标记**（不展示文本，截断文本经原生 title 提示；用户裁定：避免文本行与分隔竖线的切割感，Rail 不设分隔边框）；不含 tool/assistant。
  - 消息流新增用户消息（含流式期间发送）后条目实时出现，与消息流同源，无独立刷新动作。
  - hover 条目停留 ≥300ms 弹出浮窗：显示该轮对话快照——该条用户消息（截断 120 字符）+ 其后最后一条助手回复（截断 200 字符），纯文本（按码点截断）；浮窗为快照，流式期间不实时刷新。移开条目/浮窗或按 Esc 立即关闭；停留不足 300ms 移开不弹、不发任何请求。
  - 点击条目：消息流滚动定位到该用户消息并短暂高亮提示；随后进入**回看模式**——流式增量与新增消息不再强制滚底，对话流底部出现"回到底部"提示条，点击提示或手动滚动到底部恢复自动滚底（TD-CV-06）。
  - 草稿态/会话无任何用户消息时不渲染时间线，不留占位。
- **业务数据**：无新增持久化数据；时间线与浮窗均为已加载消息的派生只读视图。
- **交互与反馈**：时间线条目少时整列**垂直居中**；横条**悬停波浪衰减**（以悬停条为中心，邻居按距离递减伸长 22/18/15/13→12px，~200ms 缓动，指针扫过时波包平滑流动，ZCode 风格），移开收缩复位；回看选中条目保持突出（18px brand 色）并以较低波包带动邻居，直至退出回看；浮窗出现在条目右侧、靠近视口边缘自动翻转，固定宽度约 320px、最大高度约 40vh，内容超出内部滚动，出现/消失过渡 ≤150ms。
- **权限边界**：不适用（会话内只读派生视图，无权限变化、不触发资源加载）。
- **合法/非法状态流转**：浏览模式 ↔ 回看模式（点击定位进入，触底/点击提示退出，合法）；浮窗 关闭↔展示（合法）。
- **异常与边界**：用户消息无助手回复（等待中/出错）→ 浮窗显示提问 + 状态提示；超长会话（200 条用户消息）时间线内部滚动不挤占消息区；定位目标消息被工具组折叠不影响（定位到用户消息本身，永远可见）。
- **数据一致性与幂等**：时间线为消息流纯派生，切换会话随消息流重建；重复点击同一条目等价一次定位。
- **跨模块影响**：只读消费本模块消息流；不改变模块 02 切换语义与模块 04 工具卡片渲染。

验收标准：

#### 功能点：CV-S07 上下文压缩

- **目标**：长对话接近上下文上限时释放空间，且压缩过程对用户可见、可预期。
- **前置条件**：会话已激活（至少发过一条消息）；provider 已配置。
- **业务规则**：
  - 压缩能力由运行时（pi `AgentSession.compact()`）提供，forge 不自定义阈值与摘要策略。
  - **手动压缩**：输入框上下文用量区提供「压缩」入口，调用 `conversation/compact`。
  - **自动压缩**：运行时按阈值/上下文溢出自动触发，forge 侧无 RPC 入口，统一经
    `conversation.compacted` 事件通知 UI（`reason: auto`）。
  - **流式保护**：streaming 期间禁用压缩入口——运行时压缩会先 `abort` 当前轮，
    若允许点击会静默截断正在生成的回答。
- **业务数据**：压缩前后 token 数、压缩摘要、触发来源（manual / auto）。
- **交互与反馈**：
  - 手动压缩成功：入口附近显示「压缩完成：{before} → {after} tokens」，4s 后消失；
  - 手动压缩失败：显示失败原因（如「Nothing to compact」「会话未激活」）；
  - 自动压缩完成：消息区顶部出现提示条「上下文已自动压缩，历史已更新」，5s 后消失，
    并重新拉取会话历史（压缩会把 transcript 替换为摘要，不重拉则界面与真实上下文不一致）；
  - 自动压缩失败：走 `conversation.error` 上报，绝不静默。
- **权限边界**：无审批（跟 pi 一致）。
- **合法/非法状态流转**：空闲/已完成 -> 压缩中 -> 完成（合法）；streaming 期间压缩（非法，禁用入口）。
- **异常与边界**：压缩后运行时可能暂无法给出可信用量（返回 `tokens: null`），
  UI 显示「未知」而非 0，避免用户误判压缩未生效；
  重启后仅加载历史（无 lease）的会话，用量从磁盘估算（最后有效 assistant 用量
  + 尾部估算，与 pi 同规则，contextWindow 取会话模型），发出首条消息后回落为
  运行时实时读数。
- **数据一致性与幂等**：压缩失败不破坏会话历史；重复点击在压缩中与流式期间被禁用。
- **跨模块影响**：模块 05 模型 provider 提供 contextWindow（用量条上限与压缩阈值来源）。

### 3.4 页面承载

- **页面路径与访问权限**：对话区（主视图单视图或窗口画布内，会话打开后可见）。
- **页面结构**：

对话区

（扩展 CV-S06）

- **操作入口、按钮和链接**：输入框（多行）；发送按钮（运行中变取消按钮）；代码块复制按钮。（扩展 CV-S06）时间线条目（hover 预览、点击定位）；"回到底部"提示条（回看模式下显示，点击恢复自动滚底）。
- **表单字段与业务校验**：输入框非空才可发送。
- **弹窗、loading、成功/失败反馈**：
  - provider 未配置提示：触发=发送时无 provider；内容=引导配置 provider；操作=去配置。
  - 流式 loading：运行中显示状态指示。
  - 渲染错误：Mermaid 错误显示提示 + 源码。
- **失败时的上下文和数据保留**：发送失败消息可重发；流式中断保留已收内容；渲染错误不影响其他消息。

### 3.5 非功能要求

- **性能与容量**：流式 token 端到端延迟 < 100ms；Markdown 渲染 < 50ms/消息；Mermaid 渲染 < 500ms/图；消息列表滚动 60fps。（扩展 CV-S06）时间线 200 条用户消息内渲染与滚动无明显掉帧；浮窗缓存命中即显（≤50ms，派生自本地内存）、出现/消失过渡 ≤150ms；派生计算（时间线重建）在消息流变更后 ≤50ms。
- **安全与审计**：白名单渲染防 XSS；无 per-tool 审批。
- **可用性与降级**：流式中断不丢内容；渲染错误不崩溃；代码语言不支持降级纯文本。
- **可观测性**：消息发送/取消/流式中断事件记日志。
- **兼容性**：渲染组件复用 ai-coding 前端。
