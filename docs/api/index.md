# forge-core 接口设计索引（API）

> 按模块定位 forge-core 暴露的接口契约。只维护目录与状态，详细签写各模块 API 文档。

## 传输无关约定

forge-core 暴露 **方法（Method）+ 事件（Event）** 两类接口，**不绑定具体传输层**：

| 传输 | 场景 | 状态 |
|---|---|---|
| Electron IPC（invoke/handle + send） | 桌面端 v1 | 本期实现 |
| HTTP/SSE | headless v2+ | 规划中，本期不实现 |

接口签名与语义在任意传输上一致（方法=请求-响应，事件=单向推送）。方法路径命名沿用 RPC 风格（模块/方法名），**不加版本号、不加 `/api` 前缀、不在路径嵌入资源 ID**，禁止靠 HTTP 方法区分同名方法。

## 响应格式

所有方法统一返回：

```json
{ "code": 0, "message": "success", "data": { ... } }
```

| code | 含义 |
|---|---|
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 资源不存在 |
| 1004 | provider 未配置 |
| 1005 | 信任未通过 |
| 6001 | git 切换失败（data.stderr 附 git 原始错误） |
| 6002 | 组件更新失败（data.output 附更新器输出尾部） |
| 6003 | 应用更新检查失败（feed 不可达/网络失败；UI 静默处理） |
| 6004 | 应用更新下载失败/校验失败 |
| 6005 | 应用更新安装启动失败 |
| 5000 | 内部错误 |
