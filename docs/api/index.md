# API 文档

## 概述

ClaudeTask 使用 RESTful API 与 WebSocket 实现前后端通信。所有 API 统一前缀为 `/api`。

## 基础信息

| 项目 | 说明 |
|------|------|
| 基础 URL | `http://localhost:8080/api` |
| WebSocket | `ws://localhost:8080/ws` |
| 认证方式 | Token (X-Token header) |
| 数据格式 | JSON |

## 响应格式

所有 API 响应遵循统一格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| code | 说明 |
|------|------|
| 0 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 接口清单

| 编号 | 模块 | 接口数 | 说明 |
|------|------|--------|------|
| 01 | 任务管理 | 8 | Issue CRUD + 依赖 |
| 02 | 助手配置 | 8 | Agent CRUD + 技能关联 |
| 03 | 技能管理 | 8 | Skill CRUD + 附件 |
| 04 | 任务执行 | 7 | 任务领取/执行 |
| 05 | 对话功能 | 7 | 会话 + 消息 |
| 06 | 仓库配置 | 5 | 仓库 CRUD |
| 07 | 实时同步 | - | WebSocket |
| 08 | Daemon | 6 | 注册/心跳/健康检查 |

## 错误码

| code | message | 说明 |
|------|---------|------|
| 400 | 无效的请求参数 | 请求参数格式错误 |
| 401 | 未授权 | Token 无效或过期 |
| 404 | 资源不存在 | ID 不存在 |
| 409 | 资源冲突 | 唯一约束冲突 |
| 500 | 服务器错误 | 内部错误 |
