## E-SM-001 新建会话草稿态，发送首条消息后创建会话并入树

- **关联 AC**：AC-SM-001 | **优先级**：P0 | **上线门禁**：是 | **自动化等级**：mock-backend
- **角色/页面**：单用户 / 项目工作区
- **前置条件**：项目已打开（信任已过），会话池已有 ≥1 个会话
- **测试数据**：临时项目目录 + 种子会话
- **准备与清理**：起 forge；用后清理临时目录
- **操作**：
  1. 前：进入项目工作区，已有 1 个会话
  2. 中：点"新建会话" → 右侧出现输入框；**不点发送**，直接观察左侧会话树与存储
  3. 发送首条消息 → 观察左侧会话树与存储
- **断言**：
  - UI：点"新建会话"后右侧出现输入框、左侧会话树**不新增**标签；发送首条消息后树新增 1 个标签且标题为**首条消息截取**（首句，超 30 字省略；带附件发送时附件拼片段不进标题）
  - 数据：未发消息时 forge-store **无**该会话记录；发送首条消息后写入 session 记录（sessionId + cwd=项目路径 + alias=首条问题截取）
  - 负向：未发消息前不产生重复/幽灵会话；无错误提示
- **失败检查**：无 console error / 无 5xx
- **证据**：screenshot + trace

## E-SM-002 多会话并行切换观察

- **关联 AC**：AC-SM-003/008/009/010 | **优先级**：P0 | **上线门禁**：是 | **自动化等级**：mock-backend
- **角色/页面**：单用户 / 会话列表 + 主视图
- **前置条件**：≥2 会话
- **测试数据**：2 个并行会话（mock 流式事件流，各自独立序列）
- **准备与清理**：mock pi 流式；用后清会话
- **操作**：
  1. 前：2 会话均 idle
  2. 中：并行向 A、B 发消息；发到一半时点会话列表切到 B
  3. 后：观察 A、B 状态与输出
- **断言**：
  - UI：切换后主视图显示 B 的实时流式输出；A 仍 running 不暂停
  - 数据：A、B 各自输出流独立，无串扰（A 不出现 B 的 token）
  - 负向：无 A 停止、无 B 丢消息、无残留 cursor
- **健康**：无 console error / 无未捕获异常（并发下）
- **证据**：video（并发时序）+ trace

## E-SM-003 删除会话（含运行中）

- **关联 AC**：AC-SM-005/006 | **优先级**：P0 | **上线门禁**：是 | **自动化等级**：mock-backend
- **角色/页面**：单用户 / 会话列表
- **前置条件**：含 idle + running 会话
- **测试数据**：2 会话（1 idle、1 running）
- **准备与清理**：mock 流式；用后清理
- **操作**：
  1. 前：idle 会话 + running 会话各一
  2. 中：删除 idle（先取消再确认）；删除 running（直接确认）
  3. 后：观察列表与存储
- **断言**：
  - UI：二次确认弹窗文案正确；确认后列表移除
  - 数据：删除 running 时先收到 stop 事件再删 pi session；forge-store 记录删除
  - 负向：取消时不被删；未停 AgentSession 不被删
- **健康**：无 console error
- **证据**：screenshot + trace

## E-SM-004 画布开窗/吸附/置顶/关闭/跨项目

- **关联 AC**：AC-SM-011/012/013/014/015/016 | **优先级**：P0 | **上线门禁**：是 | **自动化等级**：mock-backend
- **角色/页面**：单用户 / 画布多窗口（会话池）
- **前置条件**：跨项目会话存在
- **测试数据**：2 项目各 1 会话
- **准备与清理**：mock 会话；用后清
- **操作**：
  1. 前：会话池列出跨项目会话
  2. 中：拖 A 项目会话到画布开窗 → 拖到左边缘松手 → 再拖 A 会话（重复开窗）→ 点红点关闭
  3. 后：观察画布与会话池
- **断言**：
  - UI：开窗显示会话实时内容；左边缘吸附铺满左半区；重复开窗被拒绝/聚焦已有窗口；关闭后窗口消失
  - 数据：关闭后会话仍在会话池、pi session 未删；绑定表唯一（同一会话不重复开窗）
  - 负向：无第二个 A 窗口、无会话丢失
- **健康**：无 console error；吸附/关闭后无残留
- **证据**：video（拖拽时序）+ screenshot

## E-SM-005 各吸附区/4窗格/resize/崩溃恢复

- **关联 AC**：AC-SM-017/018/019/020 | **优先级**：P1 | **上线门禁**：是 | **自动化等级**：mock-backend
- **角色/页面**：单用户 / 画布多窗口
- **前置条件**：多会话在画布
- **测试数据**：4 会话
- **准备与清理**：mock 会话；用后清
- **操作**：
  1. 前：4 会话在画布
  2. 中：依次拖窗口到右/上/下/四角（验证预览框+吸附）→ 点"4 窗格" → 拖右下角 resize → 模拟窗口崩溃后重开
  3. 后：观察各窗口布局与会话内容
- **断言**：
  - UI：右/上/下/四角各吸附区预览框出现且吸附到正确半区/象限；4 窗格后 2×2 严丝合缝；resize 受最小尺寸限制；崩溃重开后恢复已展示内容
  - 数据：窗口状态在 forge-core（崩溃后重开可从会话重建）；无串扰
  - 负向：无窗口重叠残留、无内容丢失、无未捕获异常（崩溃模拟）
- **健康**：无 console error / 崩溃处理无未捕获异常
- **证据**：video（拖拽+崩溃）+ trace
