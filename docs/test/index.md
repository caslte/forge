## 更新规则

- 每个 PRD 功能点与 AC 必须映射到至少一条测试设计；覆盖变化更新本索引。
- 测试执行状态（passed/failed 等）不写入矩阵。

## 指标口径

- 功能点设计覆盖率 = 已覆盖功能点 / 总功能点 × 100%
- 风险维度设计覆盖率 = 已覆盖适用维数 / 适用维数 × 100%
- 必测场景设计覆盖率 = 已分配必测场景 / 必测场景总数 × 100%

**必测场景口径**：必测场景 = P0 场景 + 写入/删除/审批/状态流转/权限/幂等/数据一致性类 + 一眼可见问题维度场景（页面健康/视觉布局/状态渲染/后端健康/集成完整性等，见 contract §B）。

说明：当前各模块“必测场景覆盖 100%”= 所有必测类 AC 均有测试设计，非“逐行有必测标记列”；按增强后的 contract，各矩阵应逐步给覆盖行标“必测=是/否”以可审计（随 F2/F3/F4 更新落地）。
