## 风险维度适用性

### 后端层（`file/*` 与 `git/*` 经 forge-core → IPC）

| 风险维度 | 是否适用 | 原因 | 覆盖要求 |
|---|---|---|---|
| 正常流程 | 适用 | 目录列举/读文件/git status/diff/历史查询主链路 | P0 |
| 字段边界 | 适用 | relPath 逃逸、二进制、超大文件、limit/skip 越界、sha 缩写歧义 | P0 |
| 权限角色 | 适用 | 单用户本地；但**路径逃逸是实质安全边界**（唯一把用户可控路径交给主进程读盘处） | P0 |
| 状态流转 | 不适用 | 服务层无状态机；文件 watcher 的监听生命周期归「资源生命周期」 | - |
| 异常失败 | 适用 | git 非零退出、ENOENT、权限拒绝、空仓库 exit 128 | P0 |
| 数据一致性 | 适用 | diff 必须反映真实提交内容；numstat 与 patch 不得错位 | P0 |
| 幂等 | 适用 | 只读方法重复调用须返回同值；watchSync 重复同步不叠加 watcher | P1 |
| 查询组合 | 适用 | 历史列表的 `limit`/`skip` 组合与深翻页 | P1 |
| 跨模块影响 | 适用 | 复用模块 11 `gitService`；`code.fileChanged` 事件被模块 03 引用 | P1 |
| 后端健康 | 适用 | 无未捕获异常、无吞错返回 success | P0 |
| 契约完整性 | 适用 | 每方法响应结构/错误码/合法输入不返 5xx | P0 |
| 集成完整性 | 适用 | **git 为真实外部依赖（CLI 子进程），禁止全 mock 冒充** —— core 侧用真仓库集成测 | P0 |
| 并发隔离 | 适用 | 多项目/多窗口并行拉取不串扰；共享项目状态不竞态 | P1 |
| 资源生命周期 | 适用 | `OpenFileWatcher` 创建/释放；关签后 watcher 回收 | P0 |
| 持久化完整性 | 不适用 | 本模块无持久化；布局/宽度偏好经 localStorage 属前端持久化（归前端层） | - |

### 前端层（`CodeTreePanel` / `CodeExplorer` / `CodeViewer`）

| 风险维度 | 是否适用 | 原因 | 覆盖要求 |
|---|---|---|---|
| 交互与反馈 | 适用 | 三视图切换、签操作、拖拽、右键菜单、复制浮窗、文件块展开 | P0 |
| 表单校验视图 | 不适用 | 只读视图，无输入表单（筛选框为纯前端过滤，见下） | - |
| 查询/筛选视图 | 适用 | 文件名过滤；**历史列表按说明/作者过滤（CE-S11）** | P1 |
| 页面健康 | 适用 | 每视图无 console error/pageerror/requestfailed，不崩不空白 | P0 |
| 布局完整性 | 适用 | 布局 A/B 几何、窄窗降级、元素不重叠溢出 | P0 |
| 内容正确性 | 适用 | i18n 全覆盖、无占位符/硬编码；diff 行号与内容正确 | P0 |
| 状态渲染 | 适用 | 空态/加载态/降级态/binary 态/无匹配态 | P0 |
