⬢ forge窗口形态对比原型
拖动中间分隔条调整大小 · 十字分隔条 可拖

方案 A · 你在感受什么

  • 每个会话是独立窗口，有标题栏/边框/阴影
  • 拖标题栏可独立移动，互不影响
  • 点「网格排列」一键排成 2×2；「打散」模拟手动摆
  • 窗口可拖到不同屏幕（跨屏观察）
  • tradeoff：窗口间有 OS 边框，不如分屏紧凑

方案 B · 你在感受什么

  • 4 个会话无框紧贴成 2×2，贴近 PowerShell 拆分
  • 拖中间十字分隔条调整各格大小
  • 单窗口内紧凑沉浸，无 OS 边框干扰
  • tradeoff：不能跨屏；前端需分屏引擎，改造量大
