## 已确认项（全部锁定）
1. pi 为固定基座（不再多引擎切换）。
2. **pi 集成 = 进程内 SDK**（Node 内嵌 `AgentSession`，pi 作 npm 库，扩展 in-process 拿完整 `ExtensionAPI`）。
3. **UI 形态 = web GUI**（复用 ai-coding Vue 前端；TUI 留作以后可选，v1 不做）。
4. **桌面壳 = Electron**（壳+大脑同进程，一体性；接受体积大、Wails 基建重做）。
5. **v1 范围 = 聚焦 MVP**（项目+会话+对话+工具执行+基础设置；终端/发送队列/子代理/复杂 ToolProfile 后续迭代）。
6. **嵌入式 agent = v2+**（架构已不堵死）。
7. **权限 = 跟 pi 一致**：不做自定义 per-tool 审批；继承 pi 项目信任；per-tool 审批留作 opt-in pi 扩展。
8. 不 fork pi 核心；业务能力以 pi 扩展承载，pi 可独立 `npm update`。
9. **forge-core 须为干净 Node 模块**：Electron 主进程 import；v2 嵌入式=同一 forge-core 包无头二进制。一份核心两宿主。
10. 后端重写为 Node/TS（forge-core）。

## 技术默认（用户未反对，已采纳）
- 去掉多 CLI 切换 UI（单引擎 pi）。
- 会话存储复用 pi session JSONL；forge 加项目/会话树组织层（项目=pi cwd 分组，会话=pi session）。不重造消息存储。
- 模型配置对接 pi：ToolProfile -> pi provider/model（models.json / registerProvider）。
- ai-coding 前端 `window.go.*` Wails 绑定改 Electron API；终端用 node-pty+xterm 重做（v1.1+）。

## v1 MVP 功能子集
- 项目管理（添加/选择目录）
- 多会话（新建/切换/删除，复用 pi session）
- 对话（发消息、流式响应、Markdown+代码高亮+Mermaid）
- 工具执行展示（tool call/result 卡片、Diff）
- 模型/Provider 配置（对接 pi，基础选择）
- 项目信任（pi 自带，白捡）

## v1 暂不做（后续迭代）
- 嵌入式终端（node-pty+xterm）
- 发送队列
- 子代理面板
- 复杂 ToolProfile CRUD
- 图片附件
- per-tool 审批扩展（opt-in）
- 嵌入式 agent 形态（v2+）
- TUI 形态

## 关键约束
- pi 必须可独立升级（forge 不侵入 pi 源码，pi 作 npm 依赖）。
- 业务能力以 pi 扩展承载（TS），非 fork。
- forge-core 可复用为桌面后端 + 无头服务/SDK。

## 隐含假设（待 PRD/开发压力验证）
- pi 扩展 API + SDK 足以覆盖 forge 业务能力。
- ai-coding 前端 REST+SSE 契约可由 forge-core 实现，pi 事件映射到 `CanonicalEvent`。
- ai-coding 前端可改造适配 Electron + pi。

## 非目标（v1）
- 不做多引擎可切换。
- 不 fork pi 核心源码。
- 不做 TUI 形态。
- 不做嵌入式 agent（v2+）。
- 不做自定义 per-tool 审批层（跟 pi 一致）。
- 不做沙箱（跟 pi 一致，隔离由 OS/容器负责）。
