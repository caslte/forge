# ClaudeTask - 本地 AI 任务助手平台

## 项目概述

ClaudeTask 是一款本地运行的 AI 任务管理工具，让 Claude Code 作为个人 AI 助手，自动完成开发任务并支持随时对话。

## 核心产品原则

1. **本地优先** - 所有数据存储在本地，不依赖云服务
2. **AI 原生** - AI Agent 作为核心功能而非辅助工具
3. **透明执行** - 任务执行过程实时可见，支持随时干预
4. **上下文连续** - 同一任务/会话保持 AI 上下文

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | Go + Chi | REST API + WebSocket Hub |
| 数据库 | PostgreSQL + sqlc | 类型安全 SQL |
| 前端 | Next.js (React) | Web 管理界面 |
| Agent 运行时 | Claude Code CLI | 本地执行，stdin/stdout 交互 |
| 实时通信 | gorilla/websocket | WebSocket Hub + Redis Relay |

## 核心业务流程

### 流程一：任务执行

```
1. 用户创建任务
   └── 填写标题、描述、优先级
         └── 指派给助手

2. 后台服务轮询发现新任务
   └── pollLoop() 每 3 秒调用 GET /tasks/claim

3. 领取任务，创建工作目录
   └── execenv.Prepare() 克隆仓库到 ~/multica_workspaces/{ws_id}/{task_id}/

4. 启动 Claude Code 执行
   └── claude -p --output-format stream-json
         └── 解析 JSON 流，提取 text/tool_use/tool_result

5. 实时推送执行过程
   └── WebSocket task:progress → 前端显示

6. 任务完成，清理或保留工作目录
   └── GC 24h 后自动清理
```

### 流程二：对话

```
1. 用户创建对话会话
   └── 选择助手

2. 用户发送消息
   └── POST /api/chat/sessions/:id/messages

3. 后台服务领取任务
   └── 创建 ChatTask，通过 Session 保持上下文

4. Claude Code 执行，返回流式响应
   └── WebSocket chat:message → 前端显示

5. 响应完成
   └── chat:done 广播
```
