## 🪟 多窗口模式

把每个会话开成一个独立小窗口，像便利贴一样铺满屏幕，随手摆放。

- 从左侧会话池**拖拽开窗**，自由调整大小，推到边缘自动吸附排版
- 默认**四宫格**布局，一键自动排布，一键全部关闭
- **跨项目**的会话也能摆上同一块画布——左边跑 A 项目，右边跑 B 项目，哪边有动静看哪边

![forge 多窗口模式](docs/assets/multi-window.png)

## ✨ 特性一览

**🧠 记忆** — 内置记忆模块，了解你的习惯与偏好，越用越好用——AI 不必每次重新认识你。

**📁 项目管理** — 把本地文件夹添加为项目就能开工，当前分支一眼可见，切换分支不用离开对话框。

**💬 多会话并行** — 同一个项目开多个会话同时跑，这边重构、那边修 bug，互不打架。

**👀 执行过程看得见** — AI 调了什么工具、读了哪个文件、改了哪几行，调用卡片与 Diff 并排展示，全程透明可回看。

**🤖 子 Agent 监控** — 派出去的后台任务逐个挂 Tab，进度随时点开看；可以单独叫停，也能一键全部停止。

**🔌 模型随心配** — 自由接入各家模型服务商，密钥保存在本机系统钥匙串；思考强度可调，最长支持 1M token 上下文。

**⌨️ 斜杠命令与 Skill** — 输入 `/` 唤起命令面板，pi 生态的命令与技能直接选用；Skill 支持导入与新建。

**🌿 Git 提交推送** — 对话里就能提交、推送，提交说明让 AI 替你写好。

**📸 附件随手贴** — 截图直接粘贴、文件拖进来就行，AI 拿到路径自己读。

**🌍 中英双语** — 界面文案中文 / English 一键切换。
