# forge

[English](README.md) | **简体中文**

面向 AI 辅助编程的桌面工作台 —— 项目管理、多会话对话编程、工具执行全程可视化。基于 `pi` 编码代理引擎构建。

![forge 欢迎页 — 深色主题](docs/assets/hero.png)

## 功能特性

- **项目管理** — 将本地目录注册为项目、信任处理、打开/移除、分支查看与切换
- **多会话对话** — 单项目多会话并行，跨项目多窗口并排
- **流式对话界面** — Markdown、语法高亮代码块、Mermaid 图表实时渲染
- **工具执行可视化** — 工具调用/结果卡片、状态流转、并排 Diff
- **子 Agent 监控** — 后台子 Agent 的 Tab 栏与结果视图；可停止单个或级联停止全部
- **模型与 Provider 配置** — pi `models.json` 可视化编辑、密钥安全存储、思考级别选择、1M token 上下文
